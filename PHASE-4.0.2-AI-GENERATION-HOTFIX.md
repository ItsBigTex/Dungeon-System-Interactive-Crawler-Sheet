# Phase 4.0.2 — Generative Content Engine Hotfix

- Explicit GM values are hard constraints.
- `AI Decide` is creative delegation and must be replaced with authored content.
- Item schema now supports structured weapon/effect mechanics.
- Tone instructions must become authored prose.
- Weapons require damage dice, damage type, and range.
- Requested tier/category/floor/damage type are validated.
- One automatic repair pass runs when validation fails.
- A still-invalid repair is rejected before GM approval.
- Invented mechanics must be identified as campaign rules/review flags.

No SQL migration required.
